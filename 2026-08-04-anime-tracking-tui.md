# Anime Tracking TUI

## 1. Project Base Idea

So I wanna create my own Anime Tracking TUI which takes an AniList/MAL etc token and tracks the anime and manga you are reading.

## 2. Project Idea in Detail

I plan on making this into a widget to put on `waybar` or open as a floating window, so that I can know when new episodes are released via notifications.

## 3. Programming Language(s) Planned to Use

Rust (Prototype/Final Product if it looks good), C (To learn `notcurses`), Python (To try `textual`)

## 4. Tech Stack Planned

`ratatui`, `notcurses`, `textual`
