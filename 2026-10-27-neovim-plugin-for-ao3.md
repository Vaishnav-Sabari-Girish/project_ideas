# Neovim plugin for AO3

## 1. Project Base Idea

So users can write their story in markdown in a buffer. This will be converted to HTML when uploading. 

To do this we need an AO3 account.

## 2. Project Idea in Detail

1. Write story
2. Upload (Convert to HTML automatically)
3. Each story will have it's own folder and each chapter will be in that folder.
